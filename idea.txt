Create a professional, modern Windows desktop system monitoring sidebar application with the following comprehensive requirements:

## Core Architecture
- Build using Electron + React + TypeScript for cross-platform compatibility
- Use LibreHardwareMonitor library (via node-librehardwaremonitor or C# bridge) for hardware sensor data
- Implement real-time data collection with 1-second refresh intervals
- Use WebSocket or IPC for efficient data streaming between backend and frontend

## UI/UX Requirements
- Fixed sidebar positioned on the RIGHT side of Windows desktop (380-420px width)
- Frameless, always-on-top window with transparency options
- Dark theme with neon accent colors (cyan, green, amber for warnings, red for critical)
- Smooth animations and transitions using CSS/GSAP
- Expandable/collapsible sections for each component
- Custom scrollbars and glassmorphism effects
- Professional typography (Inter or Roboto fonts)
- Responsive grid layouts for multi-core display

## Monitoring Components

### 1. CPU Monitoring (Per-Core)
- Display each physical core and logical thread individually
- Per-core: usage %, temperature (°C), current frequency (GHz), voltage
- Overall CPU: total load, package temperature, power draw (watts), fan speed
- Grid layout showing 4-8 cores per row (expandable for full view)
- Color-coded indicators: green (normal), yellow (70%+), red (85%+ or 80°C+)

### 2. GPU Monitoring (Multi-Vendor Support)
- Auto-detect NVIDIA, AMD, or Intel GPUs
- Display: GPU model, core load %, temperature, core/memory clocks, VRAM usage
- Power consumption, fan speed (% and RPM), voltage
- Support for multiple GPUs if present
- Use NVML for NVIDIA, ADL for AMD, Intel GPU API for Intel

### 3. RAM Monitoring
- Total/used/available memory in GB and percentage
- RAM speed (MHz), timings (if available), voltage
- Temperature per DIMM (if sensors available)
- Page file usage and cache memory
- XMP/DOCP profile status

### 4. Motherboard Monitoring
- Motherboard model and BIOS version
- Motherboard temperature and VRM temperature
- Voltage rails (12V, 5V, 3.3V)
- Connected fan speeds and pump speeds (AIO coolers)

### 5. Network Monitoring
- Real-time upload/download speeds (Mbps/Gbps)
- Network adapter name and connection type
- Current latency (ping to 8.8.8.8 or 1.1.1.1)
- Data usage statistics (daily/monthly totals)
- Mini real-time graph showing last 60 seconds of traffic
- Support for multiple adapters (Ethernet, WiFi, VPN)

### 6. Storage Monitoring
- All drives (NVMe, SSD, HDD) with model names
- Used/free space with visual progress bars
- Read/write speeds (current IOPS)
- Drive temperatures and health status (SMART data)
- Partition information

### 7. Security & System Health
- Windows Defender status (active/inactive)
- Firewall status
- Last virus scan date and threats detected
- Windows Update status
- System uptime
- Overall health score (calculated from all metrics)

### 8. Additional Features
- System clock and date display
- Alert system: desktop notifications for critical temps/usage
- Historical data logging (SQLite database)
- Export reports to CSV/JSON
- Screenshot capture of stats
- Customizable themes (Dark, Light, Neon, Minimal)
- Start with Windows option
- Multi-language support (English, Bengali)

```typescript
- node-notifier (alerts)
```

### Styling Guidelines
- Use CSS-in-JS (styled-components or emotion)
- Color palette:
  - Background: #0a0e27 (dark blue)
  - Accent: #00d9ff (cyan)
  - Success: #00ff88 (green)
  - Warning: #ffaa00 (amber)
  - Critical: #ff0055 (red)
  - Text: #ffffff, #a0a0a0
- Smooth transitions (0.3s ease-in-out)
- Hover effects on interactive elements
- Pulse animation for critical alerts
- Glassmorphism: backdrop-filter blur(10px) with rgba backgrounds

### Performance Optimization
- Use React.memo and useMemo for expensive renders
- Implement virtual scrolling for large core counts
- Throttle sensor polling (1s intervals, adjustable)
- Use requestAnimationFrame for smooth animations
- Lazy load charts and historical data

### Data Flow
Hardware Sensors → LibreHardwareMonitor → Node.js Backend
→ IPC/WebSocket → React Frontend → Real-time UI Updates
